以下用例是 V1 的验收与排期依据（Given / When / Then）。

## UC1：客户 → 开单 → 应收变化

**Given** 已登录（`sales` 或 `admin`）  
**When** 创建客户 A  
**And** 创建销售订单（可在订单内新增商品）  
**And** 对订单进行部分收款  
**Then** 客户 A 的“应收金额”应按订单金额 - 已收款正确计算  

## UC2：退货影响应收

**Given** 存在客户 A 与其订单  
**When** 从订单发起退货（部分/全部）  
**Then** 客户 A 的应收应减少（按退货金额）  

## UC3：针孔三联单打印（20 行分页）

**Given** 存在订单，明细行数分别为 1 / 20 / 21  
**When** 打开打印预览并执行浏览器打印  
**Then** 1、20 行为单页；21 行为分页（每页最多 20 行）  
**And** 校准偏移参数生效（x/y offset）  

## UC4：月度对账导出

**Given** 指定月份有订单、收款、退货数据  
**When** 导出该月份对账 CSV  
**Then** 汇总字段与筛选范围正确
